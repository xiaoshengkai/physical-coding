# 14 - 红外反射式传感器

## 实验目标

使用红外反射式传感器检测前方是否有障碍物。

## 硬件准备

- 树莓派 4B
- 红外反射式传感器模块
- 杜邦线若干

## 硬件连接

传感器有 4 个引脚（模块背面）：
- VCC → 树莓派 5V（Pin 2）
- GND → 树莓派 GND（Pin 6）
- OUT → 树莓派 GPIO 17（Pin 11）
- EN（使能脚）→ 不接

## 工作原理

- 传感器发射红外线
- 前方有物体（白色表面）反射 → 输出低电平（0V），指示灯亮
- 前方无物体（黑色表面）→ 输出高电平（5V）

## 运行代码

```bash
python demos/14-infrared-sensor/main.py
```

或使用快速命令：

```bash
npm run run 14
```

## 效果

- 检测到障碍物：打印 "⚠️ 检测到障碍物！"
- 无障碍物：打印 "✅ 一切正常"
- 按 Ctrl+C 退出
