# 15 - 红外传感器 + LED 反馈

## 实验目标

在实验 14 基础上添加 LED 视觉反馈，检测到障碍物时 LED 亮起。

## 硬件准备

- 树莓派 4B
- 红外反射式传感器模块
- LED（任何颜色）
- 220Ω 电阻
- 杜邦线若干

## 硬件连接

| 组件 | 引脚 | 树莓派 GPIO | 物理引脚 |
|------|------|-------------|----------|
| 红外传感器 | VCC | 5V | Pin 2 |
| 红外传感器 | GND | GND | Pin 6 |
| 红外传感器 | OUT | GPIO26 | Pin 37 |
| LED | 正极（长脚） | GPIO20 | Pin 38 |
| LED | 负极（短脚） | GND | Pin 6 |
| 电阻 | 220Ω | 串联在 LED 正极与 GPIO20 之间 | - |

**注意**：LED 必须串联电阻（220Ω），否则可能烧坏。

## 运行代码

```bash
python demos/15-infrared-led/main.py
```

或使用快速命令：

```bash
npm run run 15
```

## 效果

- 检测到障碍物：LED 亮起，打印 "⚠️ 检测到障碍物！LED 亮"
- 无障碍物：LED 熄灭，打印 "✅ 一切正常"
- 按 Ctrl+C 退出
