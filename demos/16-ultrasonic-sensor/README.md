# 16 - HC-SR04 超声波测距

## 实验目标

使用 HC-SR04 超声波传感器测量距离。

## 硬件准备

- 树莓派 4B
- HC-SR04 超声波传感器模块
- 10kΩ 电阻 × 2
- 杜邦线若干

## 硬件连接

| HC-SR04 | 树莓派 GPIO | 物理引脚 |
|---------|-------------|----------|
| VCC | 5V | Pin 2 或 4 |
| GND | GND | Pin 6 |
| Trig | GPIO23 | Pin 16 |
| Echo | GPIO24（经分压） | Pin 18 |

### 分压电路（直接拧线）

```
HC-SR04 Echo 引脚
       │
       │ (杜邦线)
       ▼
   ┌───┴───┐
   │  10k  │  ← 电阻 R1
   └───┬───┘
       │
       ├───────────────── 树莓派 GPIO24 (Pin 18)
       │
   ┌───┴───┐
   │  10k  │  ← 电阻 R2
   └───┬───┘
       │
       ▼
     GND (树莓派 Pin 6)
```

### 拧线步骤（无面包板）

1. **断电**：拔掉树莓派电源线，确保安全

2. **准备电阻**：取两只 10kΩ 电阻，将其中一个引脚（R1 的左侧引脚）与 R2 的左侧引脚拧在一起

3. **连接 GPIO24**：用一根母对母杜邦线，一端夹住电阻公共点，另一端插入树莓派 GPIO24（物理引脚 18）

4. **连接 Echo**：用另一根杜邦线，一端夹住 R1 的另一个引脚，另一端插入 HC-SR04 的 Echo 引脚

5. **连接 GND**：用第三根杜邦线，一端夹住 R2 的另一个引脚，另一端插入树莓派 GND（Pin 6）

6. **连接其他引脚**：
   - HC-SR04 VCC → 树莓派 5V（Pin 2 或 4）
   - HC-SR04 GND → 树莓派 GND（Pin 6）
   - HC-SR04 Trig → 树莓派 GPIO23（物理引脚 16）

7. **检查**：确保所有杜邦线插紧，电阻拧点处无松动，裸露金属不互相短路（可用电工胶带包裹公共点）

**分压原理**：两个 10kΩ 电阻串联，将 Echo 的 5V 高电平分压为 2.5V，满足树莓派 GPIO 的安全电压（≤3.3V）。
