# 18 - 无源蜂鸣器

## 实验目标

学习使用无源蜂鸣器，通过 PWM 输出不同频率的声音。

## 蜂鸣器类型说明

无源蜂鸣器能发出不同频率的声音，靠外部提供的特定频率脉冲信号驱动，内部没有振荡源。

| 特性 | 无源蜂鸣器 | 有源蜂鸣器 |
|------|------------|------------|
| 核心原理 | 外部脉冲信号驱动 | 内部振荡电路驱动 |
| 声音控制 | 能控制频率，可演奏不同音调 | 固定频率，只能发出一种音调 |
| 成本 | 更低 | 较高 |
| 用途 | 音乐播放器、趣味报警器 | 简单提示音 |

## 硬件准备

- 树莓派 4B
- 无源蜂鸣器模块一个
- 杜邦线 3 根

## 硬件连接

| 蜂鸣器引脚 | 树莓派 | 物理引脚 |
|------------|--------|----------|
| VCC | 5V | Pin 2 |
| GND | GND | Pin 6 |
| I/O | GPIO18 | Pin 12 |

## 运行代码

```bash
python demos/18-piezo-buzzer/main.py
```

