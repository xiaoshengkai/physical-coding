# 19 - 气体传感器

## 实验目标

使用 MQ-2 烟雾传感器检测可燃气体或烟雾。

## 传感器类型

MQ 系列气体传感器对应不同的检测对象：

| 型号 | 检测对象 |
|------|----------|
| MQ-2 | 烟雾、液化气、丙烷、氢气 |
| MQ-3 | 酒精（乙醇） |
| MQ-4 | 甲烷（天然气） |
| MQ-5 | 液化气、天然气 |
| MQ-6 | 液化石油气（LPG） |
| MQ-7 | 一氧化碳（CO） |
| MQ-8 | 氢气 |
| MQ-135 | 空气质量（苯、氨、硫化物） |

本实验使用 MQ-2。

## 硬件准备

- 树莓派 4B
- MQ-2 气体传感器模块
- 杜邦线 3 根

## 硬件连接

| 传感器引脚 | 树莓派 | 物理引脚 |
|------------|--------|----------|
| VCC | 5V | Pin 2 或 4 |
| GND | GND | Pin 6 |
| DO | GPIO17 | Pin 11 |

## 运行代码

```bash
python demos/19-gas-sensor/main.py
```

或使用快速命令：

```bash
npm run run 19
```

## 效果

- 终端实时显示检测状态
- 气体浓度超标：显示 "警告：检测到烟雾或可燃气体！"
- 环境安全：显示 "环境安全"

## 调校

1. 在洁净空气下，旋转模块上的蓝色电位器，直到信号指示灯刚好熄灭
2. 对着传感器哈气或靠近燃气（注意安全），指示灯亮起表示触发报警
